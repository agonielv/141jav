# 141jav - JavDB 清单按评分全局排序脚本

这是一个 Tampermonkey/Greasemonkey 用户脚本，用于在以下页面中把**清单所有分页**的番号卡片抓取后统一按评分从高到低排序：

- `https://javdb.com/users/list_detail?id=<清单ID>`

## 使用方法

1. 安装浏览器扩展（Tampermonkey 或 Violentmonkey）。
2. 新建脚本，把 `javdb-list-sort-by-rating.user.js` 内容粘贴进去并保存。
3. 打开任意清单详情页。
4. 点击右下角 **全清单按评分排序** 按钮。

## 说明

- 脚本会自动读取当前清单分页链接，并请求每一页的数据后统一排序。
- 排序是前端重排，不会改动你在网站上的原始清单数据。
- 默认按评分降序排列，评分相同按原清单顺序展示。
- 清单页数越多，请求时间越长，按钮会显示抓取进度。
